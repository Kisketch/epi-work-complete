## Definitions (all restated)
- Q_0 = Q_1 = 1 and Q_{j+1} = (4j+2) Q_j + Q_{j-1} for j >= 1.
- P_0 = 1, P_1 = 3 and P_{j+1} = (4j+2) P_j + P_{j-1} for j >= 1. Then P_j/Q_j -> e (given input; P_j/Q_j are convergents of a continued-fraction-type expansion of e).
- delta_j = Q_j e - P_j. It satisfies the same recurrence, and |delta_j| <= 2/Q_{j+1}.
- ||y|| = distance from y to the nearest integer.
- L = Z + Z (e+1)/2 (a rank-2 lattice in R).

## Known (THM-0003, paper-proved in Round 1)
For every real z: if z in L then j ||Q_j z|| -> 0; if z not in L then limsup_j j ||Q_j z|| >= 1/4.
Proof idea for the second half: if limsup < c < 1/4, put n_j = round(Q_j z), y_j = Q_j z - n_j (|y_j| <= c/j) and m_j = n_{j+1} - (4j+2) n_j - n_{j-1} in Z. Then y_{j+1} - (4j+2) y_j - y_{j-1} = -m_j and |m_j| <= |y_{j+1}| + (4j+2)|y_j| + |y_{j-1}| < 1 for large j, so m_j = 0 eventually. The constant 1/4 is exactly what makes the term (4j+2)|y_j| ~ 4c stay below 1.

## Question
