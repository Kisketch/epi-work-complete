## The specific theorem to generalise (THM-0003, paper-proved in Round 1)
Setup: Q_0 = Q_1 = 1, Q_{j+1} = (4j+2) Q_j + Q_{j-1} (j >= 1); P_0 = 1, P_1 = 3, same recurrence; P_j/Q_j -> e. delta_j = Q_j e - P_j. L = Z + Z (e+1)/2. ||.|| = distance to nearest integer.
Statement: for every real z, either z in L and j ||Q_j z|| -> 0, or z not in L and limsup_j j ||Q_j z|| >= 1/4.
Proof facts used: (F1) Q_{j+1} >= (4j+2) Q_j, hence Q_j -> infinity and Q_i/Q_j <= 6^{-(j-i)}. (F2) all coefficients 4j+2 are even, so u_{j+1} == u_{j-1} mod 2, and all P_j, Q_j are odd. (F3) P_j Q_{j+1} - P_{j+1} Q_j = 2(-1)^{j+1} (determinant 2, not 1, because P_0 Q_1 - P_1 Q_0 = 1 - 3 = -2), so (Q, P) and (Q, delta) are bases of the solution space of the recurrence. (F4) |delta_j| <= 2/Q_{j+1}.
Proof sketch of the lower bound: assume limsup j ||Q_j z|| < c < 1/4. With n_j = round(Q_j z), y_j = Q_j z - n_j, |y_j| <= c/j. The defect m_j = n_{j+1} - (4j+2) n_j - n_{j-1} is an integer with |m_j| <= |y_{j+1}| + (4j+2)|y_j| + |y_{j-1}| < 1 for large j, hence 0. So y satisfies the recurrence in the tail, y_j = alpha Q_j + beta delta_j; y_j -> 0 forces alpha = 0; then n_j = gamma Q_j + eps P_j with 2 gamma, 2 eps integers (Cramer, determinant 2); then z = gamma + eps e, and parity of Q_J, P_J odd yields z in L.
