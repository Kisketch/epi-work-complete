## The two results to be located in the literature

Definitions: Q_0 = Q_1 = 1 and Q_{j+1} = (4j+2) Q_j + Q_{j-1} (j >= 1); so Q_j grows like 4^j j! (super-exponential, ratio Q_{j+1}/Q_j in [4j+2, 4j+3], in particular lacunary). ||y|| = distance from y to the nearest integer.

THM-0002 (paper-proved in Round 1, exact statement): for tau >= 0 put
  F_tau = { x in [0,1] : there exist C, N with ||Q_j x|| <= C j^{-tau} for all j >= N }.
Then dim_H F_tau = max(1 - tau, 0).
(The same proof structure should work for any integer sequence q_j with q_{j+1}/q_j ~ c j and similar growth; part of your task is to find the nearest published results of this kind, not necessarily for this exact sequence.)

THM-0004 (paper-proved in Round 1, exact statement): for an integer B >= 1 and psi: N -> [0, 1/2] (no monotonicity), let W(psi) = { x : ||B Q_j x|| < psi(j) for infinitely many j }. Then W(psi) is Lebesgue-null if sum psi(j) < infinity and of full Lebesgue measure if sum psi(j) = infinity. The proof uses a quasi-independence estimate |mu(E_i cap E_j) - mu(E_i) mu(E_j)| <= 2 lambda_j N_i / N_j for i < j, Q_{j+1}/Q_j >= 6, Paley-Zygmund and reverse Fatou.
