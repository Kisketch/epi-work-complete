# Paper Audit（论文逐项审计）

按照 `AGENTS.md` 的诚实分类法与引用/形式化/计算纪律，对一篇数学论文进行逐项拆解与审计。

## 执行流程

1. **通读全文**
   - 完整阅读用户提供的 PDF 或 TeX 源文件，识别摘要、引言声称、正文全部定理/命题/引理/推论、致谢与附录。
   - 明确区分“论文自身宣称的定位”与“实际证明的命题内容”。

2. **列出全部定理与命题**
   - 按编号顺序列出文中所有主要定理、命题、推论及核心引理。

3. **逐项按 `AGENTS.md` 分类法标注**
   - 为每一项标注唯一明确类别：
     - 无条件新结果
     - 条件结果（依赖未证假设或外加公理）
     - 等价改写或换靶（与原问题难度等价，不构成进展）
     - 有限计算或有限排除（只排除有限范围）
     - 文献核查与复现（核查他人或既有结果）
   - 禁止把等价改写说成“更接近证明”，禁止把条件结果说成无条件。

4. **逐项注明证明依赖**
   - 明确列出每条结果在证明中实际依赖的：
     - Lean 公理 / 基础公理 / 白名单定理
     - 内部引理与前置命题
     - 外部文献或未审预印本（未复核的外部结果须标明条件性）
     - 数值脚本（仅作佐证，不可算作内核/严格证明）

5. **单列“作者声称 vs 实际成立”差异**
   - 专门对比摘要/引言中的强表述与正文证明实际达到的逻辑范围（例如范围限制、隐含条件、量词顺序、把换靶当降难、把自报 Lean 形式化当已复核等）。

6. **给出“真正新增了什么”的清单**
   - 剔除经典结论复述、等价改写与有限数值后，清晰列出真正新增的数学/工程内容，并严格写明**本文没有做到什么**。

## 输出格式
遵循 `AGENTS.md`：先给**一句总判断**，再给逐项对照表（`结果 | 类别 | 核查状态 | 与已有文献关系 | 依据`），随后附“作者声称 vs 实际成立”及“真正新增与未做到清单”。
