# THM-0006 (general dichotomy; generalises THM-0003)
Hypotheses (H): a_j ∈ ℤ_{>0} (j ≥ 1) with a_j → ∞; integers Q_0 ≥ 0, Q_1 ≥ 1, P_0, P_1; D := P_0Q_1 − P_1Q_0 ≠ 0; u_{j+1} = a_ju_j + u_{j-1} for P and Q.
Then θ := lim P_j/Q_j exists and is irrational; δ_j := Q_jθ − P_j satisfies |δ_j| ≤ |D|/Q_{j+1}. Let L := (ℤδ_0 + ℤδ_1)/D (a rank-2 group containing ℤ + ℤθ with index |D|). For every real z:
(A) z ∈ L ⇒ a_j‖Q_jz‖ → 0;
(B) z ∉ L ⇒ limsup_j a_j‖Q_jz‖ ≥ 1;
(C) if w_j/a_j → κ ∈ (0,∞), the same holds with weight w_j and threshold κ.
Specialisation: a_j = 4j+2, (Q_0,Q_1,P_0,P_1) = (1,1,1,3), D = −2, giving L = ℤ + ℤ(e+1)/2 and κ = 1/4, i.e. THM-0003.
Category: 5 (generalisation of THM-0003; novelty not searched; possibly classical for D = ±1).
