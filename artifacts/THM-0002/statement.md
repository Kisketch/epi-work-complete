# THM-0002 Statement (Paper 1, thm:eventual-dimension)
Let Q_0 = Q_1 = 1 and Q_{j+1} = (4j+2)Q_j + Q_{j-1} (j ≥ 1). Let ‖y‖ be the distance from y to ℤ. For τ ≥ 0 put
F_τ = {x ∈ [0,1] : ∃C, N such that ‖Q_j x‖ ≤ C j^{-τ} for all j ≥ N}.
Then dim_H F_τ = max(1−τ, 0).
