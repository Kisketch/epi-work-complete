# THM-0004 (metric Khintchine-type law along BQ_j)
For integer B ≥ 1 and any ψ: ℕ → [0, 1/2], W(ψ) = {x : ‖BQ_j x‖ < ψ(j) for infinitely many j} is Lebesgue-null if Σψ(j) < ∞ and of full measure if Σψ(j) = ∞, with no monotonicity assumption on ψ. Here Q_0 = Q_1 = 1 and Q_{j+1} = (4j+2)Q_j + Q_{j-1}.
