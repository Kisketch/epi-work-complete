## 1. S1 多层分裂质量界（L2541-2543）
论文式：mu(I_j) 不超过连乘_{i} (C_1 i^{-b})，等于 exp(-b j log j 加 O(j))。
显式展开：连乘等于 C_1^{j-j_0} 乘 exp(-b 求和 log i)；
求和 log i 等于 j log j 减 j 加 O(log j)（Stirling 或积分比较）；
故 log mu 不超过 -b j log j 加 (log C_1 加 b) 乘 j 加 O(log j)。
O(j) 常数项来源：(i) 每层 log C_1 得 (j-j_0) log C_1；(ii) 阶乘对数余项正 b 乘 j；
(iii) 起始层 j_0 平移常数进 O(1)；(iv) O(log j) 尾项被 O(j) 吸收。
C_1 来源：分支数下界每层至少 c 乘 i^b 的倒数；c 来自 L2451-2464 莫比乌斯计数与 L2526-2527 区间长。
状态：纸面待建。缺引理 LEM-prod-mu-bound：输入 j 不小于 j_0 且每层分支至少 c 乘 i^b；
结论为上式连乘界及其 exp 形式，O(j) 系数显式为 log C_1 加 b。
## 2. S2 柱长双边界加窗交数 17 等于 15 加 2（L2545-2551）
柱长上界：|I_j| 不超过 1/u squared，不超过 1/(4H_j/3) squared，等于 (9/16) H_j^{-2}；
柱长下界：|I_j| 不小于 1/(2u squared)，不小于 1/(2(5H_j/2) squared)，等于 (2/25) H_j^{-2}；
与论文 (25/2)^{-1} H_j^{-2} 到 (9/16) H_j^{-2} 逐字一致。不同柱内部不交。
交数构成：记最小柱长 d_min 等于 (2/25) H_j^{-2}。论文分解为两部分：
内部部分 ceil(h/d_min) 加 2 不超过 15；端点部分至多再加 2 个；总计 17。
验算 15：h 不超过 H_j^{-2}，故 h/d_min 不超过 25/2 等于 12.5，ceil 不超过 13，加 2 得 15。
故 mu(U) 不超过 17 乘 max mu(I_j)，即 L2554 的系数 17。
状态：纸面待建。缺 LEM-cylinder-length（输入 u 区间与 0 小于 v 小于 u，结论双边界常数 2/25 与 9/16）；
缺 LEM-window-meet-card（输入 D5 加柱族不交加最小柱长，结论基数不超过 17）。

## 4. S4：2 log H_{j+1} 等于 2j log j 加 O(j)（L2552，源头 L2416）
论文在 L2552 写 log(h^{-1}) 不超过 2 log H_{j+1} 等于 2j log j 加 O(j)；
右端是 L2416 的两倍，指标 j 加 1 与 j 之差被 O(j) 吸收，因差为 log j 加 O(1)。

## 5. S5 组装 O(h^s) 与 s 小于 b/2 条件（L2553-2556）
第一步 mu(U) 不超过 17 exp(-b j log j 加 O(j))，即 S1 上确界乘 S2 交数；
第二步 -b j log j 拆为 -2s j log j 减 (b-2s) j log j，纯代数，无常数。
第三步 h^s 不小于 exp(-2s j log j 加 O(j))，由 D5 左端加 S4 得到，O(j) 系数为 2s 乘 S4 系数；
第四步比值 mu(U)/h^s 不超过 17 exp(-(b-2s) j log j 加二合一余项)。
最终常数 C 依赖 C_1、j_0、b、s、S4 系数与阈值 J_0；固定 s 小于 b/2 时指数项主导线性余项。
s 小于 b/2 作用：恰为 (b-2s) 大于 0，使负二次对数项压住线性余项；
s 等于 b/2 时比值为 exp(O余项) 无界，论文未证一致有界；s 大于 b/2 时发散。
b 等于 2 得维数至少 1，b 等于 1 得维数至少 1/2（L2557-2559 质量分布原理出口）。
状态：纸面待建。缺 LEM-final-frostman-bound：输入 S1-S4 显式界加 0 小于 s 小于 b/2；
结论为存在 C 与 J_0 使 j 不小于 J_0 时 mu(U) 不超过 C h^s，C 与 J_0 对参数显式依赖。
