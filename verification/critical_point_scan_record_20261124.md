## 1. 对象与定义（照录，tex 3797–3821 / Lean `ResidueMultiAsymptotic.lean` 520–522、1105–1113）

- $\mathcal A_{m,S,B}:=\{a\in\Z_{\ge1}:(\exists r\in S,\ a\ge r\wedge a\equiv r\pmod m)\ \text{or}\ (\exists b\in B,\ \exists k\ge1,\ a+b=km)\}$，$S\subset\Z_{\ge1}$、$B\subset\Z_{\ge0}$ 有限，$d=|S|+|B|\ge1$。
- $F_{m,S,B}:=\{[0;a_1,a_2,\dots]:a_n\in\mathcal A_{m,S,B}\ \forall n\}$；特例 $F_{m,\{r\},\emptyset}=F_{m,r}$，$F_{m,\emptyset,\{0\}}=F_{m,m}$。
- $W_S(p,n):=\sum_{w\in S^n}q(w)^{-p}$，$s_0(S):=\inf\{s>0:\sum_n W_S(2s,n)<\infty\}$（`poincareAbscissa`），$C_S(p):=\sum_n W_S(p,n)$。
- 已证（`thm:multi-residue-asymptotic`，仓库口径）：$\dimH F_{m,S,B}\to\max(1/2,s_0(S))$；次临界三阶渐近 $\dimH F_{m,S,B}=\tfrac12+\tfrac{dC_S}{2m}-\tfrac{(dC_S)^2\log m}{2m^2}\cdot\!(\text{经 } \gamma,C_S'\text{ 修正})\!+O((\log m)^2/m^3)$；超临界 $\dimH F_{m,S,B}-s_0=\Theta(m^{-2s_0})$。

## 2. 方法

- 复用 R7（`asymptotic_residues_check_20261123.py`）的 Chebyshev 配点法，推广到一般 $\mathcal A_{m,S,B}$：$L_s(y^j)(x)=\sum_{r\in S}m^{-(2s+j)}\zeta(2s+j,\tfrac{r+x}{m})+\sum_{b\in B}m^{-(2s+j)}\zeta(2s+j,k_0+\tfrac{x-b}{m})$，$k_0=\lceil (b+1)/m\rceil$；维数估计 = 谱半径为 1 的 $s$（二分，dps=30，$n=16$；$n=24$ 校验）。$s_0(S)$ 用有限字母表算子 $L^S_sf=\sum_{a\in S}(a+x)^{-2s}f(1/(a+x))$ 的谱半径为 1 的 $s$（$n=24$）。
- **自检**：$S=\{r\},B=\emptyset$ 在 `tab:residues-general` 的 10 条内核核验开括号（$m=2..6$，$r\in\{1,m\}$）**10/10 落入括号内**（例：$m=4,r=1$ 得 0.698839 ∈ (0.697266, 0.699219)）。
- **配点收敛**：$n=16$ 与 $n=24$ 之差在 $10^{-15}$ 量级（18 处校验点全部 $\le 7.1\times10^{-15}$），估计值本身已收敛。
- **见证一致性**：$s_0(\{2,3\})=0.337437<1/2$，$s_0(\{1,2\})=0.531281\ge 0.51$，与论文二见证集合一致。

**形态结论（数值）**：
1. **临界慢化**：$s_0$ 越接近 $1/2$，固定 $m$ 处的 $\alpha_{\rm loc}$ 越低；两侧在 $|s_0-1/2|\lesssim0.003$ 时 $\alpha_{\rm loc}\approx0.46$–$0.55$，即 $\Delta\approx m^{-1/2}$，与名义渐近指数（1 或 $2s_0$）明显不同。
2. **连续性**：$\Delta(16384)$ 随 $s_0\to1/2$ 两侧连续变化，无跳跃迹象。
3. 深次临界（$\{2,3\}$）与远离临界的超临界（$\{1,2\}$）均回到已证渐近。

## 5. 标度模型与零自由参数验证（`critical_scaling_check_20261124.py`）

**模型（启发式，由 S15 尾方程导出）**：把 $C_S(p)$ 在极点 $p=2s_0$ 附近写成 $\kappa(S)/(p-2s_0)$，尾方程 $d\,C_S(1+\varepsilon)\,m^{-1-\varepsilon}\zeta(1+\varepsilon)=1$ 化为
$$\varepsilon(\varepsilon+\eta)\,m^{1+\varepsilon}=d\,\kappa(S),\qquad \varepsilon=2\dimH F_{m,S,B}-1,\ \ \eta=1-2s_0(S).$$
**独立预测的常数**：$\kappa(S)=c(S)/(-\rho'_S(2s_0))$，$c=\lim_n W_S(2s_0,n)$（PF 极限，配点迭代得），$\rho'_S$ 为有限字母表算子谱半径的导数（中心差分）。近临界族 $\kappa\approx0.674$–$0.682$；$\kappa(\{1,2\})=2.092$，$\kappa(\{2,3\})=1.069$，$\kappa(\{2,3,4\})=0.993$。

- 近临界与超临界组：比值随 $m$ 单调趋于 1，与「丢掉 $O(\varepsilon)$ 项」的预期一致；$d$ 的线性性（$B=\{1\}$）同样成立。
- 深次临界 $\{2,3\}$ 的恒定偏差 1.19 = $C_S(1)_{\rm 真}/(\kappa/\eta)=3.90/3.29$，恰为极点近似远离极点时的已知误差（$C_S(1)$ 真值由已证渐近 $m\Delta\to dC_S/2=3.90$ 反推），模型结构自洽。
- **超临界精确前因子**：模型预测 $\dimH F_{m,S,B}-s_0\sim\frac{d\kappa}{2(2s_0-1)}m^{-2s_0}$；对 $\{1,2\}$ 预测常数 33.43，扫描在 $m=16384$ 测得 $m^{2s_0}\Delta=32.86$（差 2%）。此常数正是 README §五.2(c) 列为「尚未解决」的项。

## 6. 由数据支持的论断（全部为数值/启发式，待证）

- **临界指数 $1/2$**：$s_0(S)=1/2$ 时 $\dimH F_{m,S,B}-1/2\approx\frac{\sqrt{d\kappa(S)}}{2}\,m^{-1/2}$，无对数修正迹象（$\varepsilon\log m\to0$）。
- **交叉尺度** $m^*=d\kappa/\eta^2$：$m\ll m^*$ 为临界窗（$m^{-1/2}$），$m\gg m^*$ 回到已证的两支渐近。
- **标度函数**：$\varepsilon=m^{-1/2}\Phi(\eta m^{1/2})$ 的隐式形式即 $\varepsilon(\varepsilon+\eta)m^{1+\varepsilon}=d\kappa$；$\Phi(x)\to\sqrt{d\kappa}$（$x\to0$），$\Phi(x)\sim d\kappa/|x|$（次临界侧大 $|x|$），$\Phi(x)\sim x+d\kappa/x$（超临界侧大 $x$，忽略 $m^{-\varepsilon}$ 修正）。
