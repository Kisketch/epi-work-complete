## 二、数学定理完整严格证明

### 2.1 定理 1（全谱完全离散化与无穷等距谱隙，论文二 Theorem 6 & Corollary 7）

**定理陈述**：设 $Q_j$ 为 $e$ 的选定收敛子分母，满足
$$Q_{j+1} = (4j+2)Q_j + Q_{j-1} \quad (j \ge 1, \ Q_0=1, \ Q_1=1, \ Q_2=7).$$
对任意 $x \in \mathbb{R}$，记 $M_j = \mathrm{round}(Q_j x) \in \mathbb{Z}$，$u_j = Q_j x - M_j \in [-1/2, 1/2]$（故 $\|Q_j x\| = |u_j|$），并定义整数递推缺陷（数字）
$$d_j(x) := M_{j+1} - (4j+2)M_j - M_{j-1} \in \mathbb{Z} \qquad (j \ge 1).$$
则：
1. 对任意满足 $\Lambda(x) = \limsup_{j\to\infty} j\|Q_j x\| < \infty$ 的 $x \in \mathbb{R}$，有 $u_j = O(1/j) \to 0$，且
   $$\lim_{j\to\infty} \bigl(d_j(x) - 4j u_j(x)\bigr) = 0, \qquad \lim_{j\to\infty} \bigl(|d_j(x)| - 4j\|Q_j x\|\bigr) = 0.$$
2. $\Lambda$ 的完整谱集满足精确恒等式：
   $$\Lambda(\mathbb{R}) = \frac{1}{4}\mathbb{Z}_{\ge 0} \cup \{\infty\} = \left\{0, \frac{1}{4}, \frac{1}{2}, \frac{3}{4}, 1, \dots\right\} \cup \{\infty\}.$$
3. 对每个非负整数 $k \in \mathbb{Z}_{\ge 0}$，开区间 $\bigl(\frac{k}{4}, \frac{k+1}{4}\bigr)$ 均为 $\Lambda$ 的无条件空谱隙；对任意 $c \in \bigl[\frac{k}{4}, \frac{k+1}{4}\bigr)$，次能级水平集恒等：$E_c = E_{k/4} = \{x \in \mathbb{R} : \limsup_{j\to\infty} |d_j(x)| \le k\}$。

**证明**：
1. 将 $M_j = Q_j x - u_j$ 代入分母递推 $Q_{j+1} - (4j+2)Q_j - Q_{j-1} = 0$，消去含 $x$ 的主项，得纯代数恒等式：
   $$d_j(x) = (4j+2)u_j - u_{j+1} + u_{j-1} \qquad (j \ge 1).$$
   因此
   $$d_j(x) - 4j u_j = 2u_j - u_{j+1} + u_{j-1}.$$
   若 $\Lambda(x) < \infty$，取有限实数 $C = \Lambda(x) + 1$，则最终 $j|u_j| = j\|Q_j x\| \le C$，即 $|u_j| \le C/j \to 0$。从而 $2u_j - u_{j+1} + u_{j-1} \to 0$，即 $d_j(x) - 4j u_j(x) \to 0$。由反三角不等式
   $$\bigl||d_j(x)| - 4j|u_j(x)|\bigr| = \bigl||d_j(x)| - |4j u_j(x)|\bigr| \le |d_j(x) - 4j u_j(x)| \to 0,$$
   立得 $|d_j(x)| - 4j\|Q_j x\| \to 0$。
2. 对任意 $\Lambda(x) < \infty$ 的 $x \in \mathbb{R}$，由 $|d_j(x)| - 4j\|Q_j x\| \to 0$ 知
   $$4\Lambda(x) = \limsup_{j\to\infty} 4j\|Q_j x\| = \limsup_{j\to\infty} |d_j(x)|.$$
   由于 $|d_j(x)| \in \mathbb{Z}_{\ge 0}$ 是非负整数序列，任何非负整数序列的上极限只能是非负整数 $k \in \mathbb{Z}_{\ge 0}$ 或 $+\infty$。因此 $4\Lambda(x) \in \mathbb{Z}_{\ge 0}$，即 $\Lambda(x) \in \frac{1}{4}\mathbb{Z}_{\ge 0}$。这证明了 $\Lambda(\mathbb{R}) \subseteq \frac{1}{4}\mathbb{Z}_{\ge 0} \cup \{\infty\}$。
3. 反之，验证每个能级均可达到：
   - $k = 0$：对 $x \in L = \mathbb{Z} + \mathbb{Z}\frac{e+1}{2}$（例如 $x = 0$ 或 $x = e$），有 $\Lambda(x) = 0$；
   - $\infty$：由论文二 Section 5 的全测度论证，Lebesgue 几乎处处的 $x \in \mathbb{R}$ 满足 $\Lambda(x) = \infty$；
   - $k \in \mathbb{Z}_{\ge 1}$：取充分大的起始下标 $N$（使 $4k/Q_{N+1} < 1/8$ 且 $2k/N < 1/8$），令 $M_{N-1}=M_N=0$，对所有 $j \ge N$ 规定常值数字 $d_j \equiv k$，由递推 $M_{j+1} = (4j+2)M_j + M_{j-1} + k$ 生成整数序列 $M_j$。记 $W_j = M_{j+1}Q_j - M_j Q_{j+1}$，则 $W_j = k Q_j - W_{j-1}$（$W_{N-1}=0$），归纳得 $|W_j| \le 2k Q_j$。由裂项级数 $M_{j+1}/Q_{j+1} - M_j/Q_j = W_j/(Q_j Q_{j+1})$ 收敛到极限 $x_k = \lim_{j\to\infty} M_j/Q_j$，且对所有 $j \ge N$ 有
     $$|Q_j x_k - M_j| \le \frac{4k Q_j}{Q_{j+1}} \le \frac{k}{j} < \frac{1}{2}.$$
     故 $M_j = \mathrm{round}(Q_j x_k)$ 确为最近整数，其真实缺陷 $d_j(x_k) = k$（$j \ge N$），从而 $4j\|Q_j x_k\| \to k$，即 $\Lambda(x_k) = k/4$。 $\blacksquare$

### 2.2 定理 2（正能级 $c = k/4$ 精确三分法，论文二 Theorem 13）

**定理陈述**：固定正整数 $k \in \mathbb{Z}_{\ge 1}$。在能级 $c = k/4$ 处，以下三类集合具有截然不同的分形/代数结构：
1. **上极限水平集（$2k+1$ 分支字母表，规范底数 $2k+1$）**：
   $$x \in E_{k/4} = \{x \in \mathbb{R} : \Lambda(x) \le k/4\} \iff u_j(x) \to 0 \text{ 且最终 } d_j(x) \in \{-k, -k+1, \dots, k\}.$$
   在圆周 $\mathbb{R}/\mathbb{Z}$ 上，对插值规范函数 $h_k(1/Q_n) = (2k+1)^{-n}$，精确上极限水平集 $\{\Lambda = k/4\}$ 具有无穷且 $\sigma$-有限的 $\mathcal{H}^{h_k}$ 测度，严格次水平集 $\{\Lambda < k/4\} = E_{(k-1)/4}$ 的 $\mathcal{H}^{h_k}$ 测度为 $0$。
2. **无符号精确极限集（普适 $2$ 分支字母表，规范底数恒为 $2$，与 $k \ge 1$ 无关）**：
   定义 $E_{\mathrm{lim}}(k/4) := \{x \in \mathbb{R} : \lim_{j\to\infty} j\|Q_j x\| = k/4\}$。则
   $$x \in E_{\mathrm{lim}}(k/4) \iff u_j(x) \to 0 \text{ 且最终 } |d_j(x)| = k \iff u_j(x) \to 0 \text{ 且最终 } d_j(x) \in \{-k, +k\}.$$
   因为对任意 $k \ge 1$，二元字母表 $\{-k, +k\}$ 的基数恒为 **$2$**（与 $k$ 的大小无关！），故在插值规范族 $g_b(1/Q_n) = b^{-n}$ 中，$E_{\mathrm{lim}}(k/4)$ 的临界 Hausdorff 规范函数恒为 $h_{\mathrm{lim}} := g_2$（$h_{\mathrm{lim}}(1/Q_n) = 2^{-n}$）：在 $\mathbb{R}/\mathbb{Z}$ 上，$E_{\mathrm{lim}}(k/4)$ 具有无穷且 $\sigma$-有限的 $\mathcal{H}^{g_2}$ 测度（而在规范 $h_k = g_{2k+1}$ 下测度为 $0$，因 $2 < 2k+1$）。此外，对一切 $c \notin \frac{1}{4}\mathbb{Z}_{\ge 0}$，有 $E_{\mathrm{lim}}(c) = \emptyset$。
3. **有符号精确极限集（唯一尾分支，坍缩为单个可数 $L$-陪集）**：
   对每个符号 $\pm$，定义 $E_{\mathrm{lim}}^\pm(k/4) := \{x \in \mathbb{R} : \lim_{j\to\infty} j u_j(x) = \pm k/4\}$。则
   $$x \in E_{\mathrm{lim}}^\pm(k/4) \iff u_j(x) \to 0 \text{ 且最终 } d_j(x) = \pm k.$$
   对任意两点 $x, y \in E_{\mathrm{lim}}^\pm(k/4)$，必有 $x - y \in L = \mathbb{Z} + \mathbb{Z}\frac{e+1}{2}$。从而每个有符号精确极限集严格等于格 $L$ 的**单个可数陪集**：
   $$E_{\mathrm{lim}}^+(k/4) = x_k^+ + L, \qquad E_{\mathrm{lim}}^-(k/4) = x_k^- + L \quad (x_k^- = -x_k^+),$$
   故其为可数集，Hausdorff 维数及任何非原子连续规范下的 Hausdorff 测度均为 $0$。

**证明**：
- **(1)** 由定理 1 与论文二 Theorem 12（Critical gauge theorem）直接给出。
- **(2)** 若 $j\|Q_j x\| \to k/4$，则 $|u_j(x)| = O(1/j) \to 0$，由 $|d_j(x)| - 4j\|Q_j x\| \to 0$ 得 $|d_j(x)| \to k$。因为 $|d_j(x)| \in \mathbb{Z}_{\ge 0}$，当 $|d_j(x)| - k \in (-1, 1)$ 时必有 $|d_j(x)| = k$，即对充分大的 $j$ 恒有 $d_j(x) \in \{-k, +k\}$。反之，若 $u_j(x) \to 0$ 且最终 $d_j(x) \in \{-k, +k\}$，则 $|d_j(x)| = k$，故 $4j\|Q_j x\| \to k$。
  将 Theorem 12 的覆盖上界与 Cantor 树质量分布下界中的数字字母表从 $\{-k,\dots,k\}$（基数 $2k+1$）替换为二元集 $\{-k, +k\}$（基数 $2$）：每个起始等价类在第 $n$ 层的存活中心数至多为 $2^{n-N}$，而在固定起始下标 $N$ 的二元数字空间 $\{-k,+k\}^{\{j \ge N\}}$ 上赋予 $(1/2, 1/2)$ 独立乘积伯努利测度，对任意长度 $1/Q_{n+1} \le h < 1/Q_n$ 的区间，其测度至多为 $3 \cdot 2^{-(n-N)} \le 3 \cdot 2^{N+1} g_2(h)$。由质量分布原理与 $L$ 平移不变性（对 $y \in L$ 有 $j\|Q_j y\| \to 0$，故 $E_{\mathrm{lim}}(k/4)$ 在模 $1$ 下同样是 $L$-不变 Borel 集），知 $E_{\mathrm{lim}}(k/4)$ 在 $\mathbb{R}/\mathbb{Z}$ 上具有无穷且 $\sigma$-有限的 $\mathcal{H}^{g_2}$ 测度。
- **(3)** 由有符号渐近式 $d_j(x) - 4j u_j(x) \to 0$ 知，$j u_j(x) \to \pm k/4 \iff u_j(x) \to 0 \text{ 且 } d_j(x) \to \pm k \iff u_j(x) \to 0 \text{ 且最终 } d_j(x) = \pm k$。
  设 $x, y \in E_{\mathrm{lim}}^\pm(k/4)$，则 $j\bigl(u_j(x) - u_j(y)\bigr) \to 0$。注意到
  $$Q_j(x - y) = \bigl(M_j(x) - M_j(y)\bigr) + \bigl(u_j(x) - u_j(y)\bigr),$$
  其中 $M_j(x) - M_j(y) \in \mathbb{Z}$ 是整数，因此到最近整数的距离满足
  $$\|Q_j(x - y)\| \le |u_j(x) - u_j(y)|.$$
  两边乘以 $j \ge 0$ 并由夹逼定理得 $j\|Q_j(x - y)\| \to 0$。由分类定理（Theorem 1 / `Classification.theorem2_classification`），立得 $x - y \in L = \mathbb{Z} + \mathbb{Z}\frac{e+1}{2}$！
  反之，若 $z \in L$，则 $j\|Q_j z\| \to 0$；对 $x \in E_{\mathrm{lim}}^\pm(k/4)$，由于 $u_j(x) = O(1/j) \to 0$ 且 $u_j(z) = o(1/j) \to 0$，对充分大的 $j$ 有 $|u_j(x) + u_j(z)| < 1/2$，故 $\mathrm{round}(Q_j(x+z)) = M_j(x) + M_j(z)$，从而 $u_j(x+z) = u_j(x) + u_j(z)$，得 $j u_j(x+z) = j u_j(x) + j u_j(z) \to \pm k/4 + 0 = \pm k/4$，即 $x + z \in E_{\mathrm{lim}}^\pm(k/4)$。因此 $E_{\mathrm{lim}}^\pm(k/4) = x_k^\pm + L$。 $\blacksquare$

### 2.3 定理 3（一般线性增长递推 $Q_{j+1}=(cj+d)Q_j+Q_{j-1}$ 的统一推广，论文二 Theorem 14）

**定理陈述**：设 $c \in \mathbb{Z}_{\ge 1}, d \in \mathbb{Z}$，正整数序列 $(Q_j)_{j \ge 0}$ 对 $j \ge J_0$（其中 $c J_0 + d \ge 2$）满足
$$Q_{j+1} = (cj + d)Q_j + Q_{j-1}.$$
定义 $\Lambda^{(c,d)}(x) := \limsup_{j\to\infty} j\|Q_j x\|$ 及 $\Lambda_\alpha^{(c,d)}(x) := \limsup_{j\to\infty} j^\alpha \|Q_j x\|$（$0 \le \alpha \le 1$）。则：
1. 对任意满足 $\Lambda^{(c,d)}(x) < \infty$ 的 $x \in \mathbb{R}$，整数缺陷 $d_j := M_{j+1} - (cj+d)M_j - M_{j-1} \in \mathbb{Z}$ 满足
   $$\lim_{j\to\infty} (d_j - c j u_j) = 0, \qquad \lim_{j\to\infty} (|d_j| - c j \|Q_j x\|) = 0.$$
2. $\Lambda^{(c,d)}$ 的全谱以 $1/c$ 为量子化步长完全离散化：
   $$\Lambda^{(c,d)}(\mathbb{R}) = \frac{1}{c}\mathbb{Z}_{\ge 0} \cup \{\infty\} = \left\{0, \frac{1}{c}, \frac{2}{c}, \frac{3}{c}, \dots\right\} \cup \{\infty\},$$
   每个开区间 $\bigl(\frac{k}{c}, \frac{k+1}{c}\bigr)$（$k \in \mathbb{Z}_{\ge 0}$）均为无条件空谱隙。
3. 每个有限水平集 $\{\Lambda^{(c,d)} \le t\}$ 的 Hausdorff 维数均为 $0$；对一切次临界权重 $0 \le \alpha < 1$ 与有限 $t \ge 0$（$\alpha=0$ 时 $t \le 1/2$），有
   $$\dim_H \{x \in [0,1] : j^\alpha \|Q_j x\| \to t\} = \dim_H \{x \in \mathbb{R} : \Lambda_\alpha^{(c,d)}(x) \le t\} = 1 - \alpha.$$

**证明**：将 $M_j = Q_j x - u_j$ 代入 $Q_{j+1} = (cj+d)Q_j + Q_{j-1}$ 得 $d_j = (cj+d)u_j - u_{j+1} + u_{j-1}$，故 $d_j - c j u_j = d u_j - u_{j+1} + u_{j-1} \to 0$（当 $u_j \to 0$），导出 $c\Lambda^{(c,d)}(x) = \limsup_j |d_j| \in \mathbb{Z}_{\ge 0} \cup \{\infty\}$。常值数字 $d_j \equiv k$ 的裂项求和利用 $Q_{j+1}/Q_j \ge cj+d \to \infty$ 给出 $|u_j| \le 2k/(cj) < 1/2$（大 $j$），实现每个能级 $k/c$。最后，由 $Q_{j+1}/Q_j = cj + O(1)$ 与 $\log Q_n = n\log n + O(n)$，Theorem 9–11 的覆盖上界与平移网格 Moran 下界将常数 $4$ 替换为 $c$ 后原样成立。 $\blacksquare$

## 四、Python/`mpmath` 100 位高精度验证摘要

脚本：`verification/verify_full_spectrum_discrete.py`，日志：`verification/verify_full_spectrum_discrete.log`（工作精度 `mp.dps = 100`）。

1. **实验 1（离散能级 $k/4$ 显式见证点与 $O(1/j)$ 收敛速率）**：
   - 对 $k = 0, 1, 2, 3, 4$，由常值缺陷 $d_j \equiv k$（$j \ge 4$）构造 $x_k^+$，在 $j = 50$ 处验证 $j\|Q_j x_k^+\|$ 分别达到 $0.0$, $0.24747623251642$, $0.49495246503284$, $0.74242869759473$, $0.98990493006568$，且 $j \cdot \bigl||d_j| - 4j\|Q_j x_k^+\|\bigr| \approx 0.50475 k$，严格符合 $O(1/j)$ 渐近律。
2. **实验 2（同有符号极限两点之差落入 $L = \mathbb{Z} + \mathbb{Z}\frac{e+1}{2}$ 的 100 位验证）**：
   - 对 $k = 1, 2, 3, 4$，将 $j = 4, 5$ 的缺陷微扰为 $0, -1$ 而在 $j \ge 6$ 恢复 $d_j = k$ 得到 $x_k'^+$。由 Cramér 行列式公式精确解出整数对 $(m, n) \in \mathbb{Z}^2$：
     - $k=1$: $(m, n) = (-65399, 35177)$，$\bigl|(x_1'^+ - x_1^+) - (m + n\frac{e+1}{2})\bigr| = 2.4396 \times 10^{-98}$；
     - $k=2$: $(m, n) = (-97168, 52265)$，残差 $= 1.9703 \times 10^{-97}$；
     - $k=3$: $(m, n) = (-128937, 69353)$，残差 $= 5.1788 \times 10^{-97}$；
     - $k=4$: $(m, n) = (-160706, 86441)$，残差 $= 2.9645 \times 10^{-97}$。
3. **实验 3（交替二值分支 $d_j = (-1)^j k \in \{-k, +k\}$ 的无符号收敛与有符号振荡）**：
   - 对 $k = 1, 2, 3, 4$，在 $j = 40, 41$ 处验证无符号序列 $j\|Q_j x_k^{\mathrm{alt}}\|$ 单调收敛于 $k/4$，而有符号序列 $j\varepsilon_j(x_k^{\mathrm{alt}})$ 在 $+k/4$ 与 $-k/4$ 之间严格交替振荡，证实 $E_{\mathrm{lim}}(k/4) \supsetneq E_{\mathrm{lim}}^+(k/4) \cup E_{\mathrm{lim}}^-(k/4)$。
4. **实验 4（一般线性增长递推 $Q_{j+1}=(cj+d)Q_j+Q_{j-1}$ 的 $k/c$ 离散能级）**：
   - 对 $(c,d) = (2,1)$（步长 $1/2$，能级 $0.5, 1.0, 1.5$）与 $(c,d) = (6,3)$（步长 $1/6$，能级 $1/6, 1/3, 1/2$），在 $j=50$ 处验证 $\bigl||d_j| - c j \|Q_j^{(c,d)} x_k\|\bigr| \approx 0.01 k$。
