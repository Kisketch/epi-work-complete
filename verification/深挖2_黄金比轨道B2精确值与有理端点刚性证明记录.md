## 2. 完整数学推导与证明

### 2.1 一般有理端点 $(u,v) = (p_1/q_1, p_2/q_2)$ 的线性-范数恒等式与模 $5$ 分歧

设 $u = p_1/q_1$、$v = p_2/q_2$ 为有理数，满足 $q_1, q_2 \in \mathbb{Z}_{>0}$ 且
$$D := q_1 q_2 (u + v) = p_1 q_2 + p_2 q_1 \in \mathbb{Z}_{>0}.$$
对任意黄金比轨道点 $\eta = \frac{a\varphi + b}{c\varphi + d} \in E_\varphi$（其中 $a,b,c,d \in \mathbb{Z}$，$\varepsilon := ad - bc \in \{\pm 1\}$），记
$$\xi_1 := (p_1 c - q_1 a)\varphi + (p_1 d - q_1 b) \in \mathbb{Z}[\varphi], \qquad \xi_2 := (q_2 a + p_2 c)\varphi + (q_2 b + p_2 d) \in \mathbb{Z}[\varphi].$$
由 $u - \eta = \frac{\xi_1}{q_1(c\varphi+d)}$、$\eta' + v = \frac{\xi_2'}{q_2(c\varphi'+d)}$ 以及高度公式 $h(\eta) = \frac{2|(c\varphi+d)(c\varphi'+d)|}{\sqrt{5}}$，分母因子 $|(c\varphi+d)(c\varphi'+d)|$ 精确对消，局部极限泛函化为：
$$\Phi_{u,v}(\eta) := h(\eta)\frac{|u - \eta|\,|\eta' + v|}{u + v} = \frac{2|\xi_1 \xi_2'|}{D\sqrt{5}}.$$
利用 $\varphi = \frac{1+\sqrt{5}}{2}$、$\varphi' = \frac{1-\sqrt{5}}{2}$、$\varphi\varphi' = -1$、$\varphi+\varphi' = 1$ 展开 $2\xi_1\xi_2'$：
- $\sqrt{5}$ 项系数为
  $$(p_1 c - q_1 a)(q_2 b + p_2 d) - (p_1 d - q_1 b)(q_2 a + p_2 c) = -(ad - bc)(p_1 q_2 + p_2 q_1) = -\varepsilon D;$$
- 有理部为整数
  $$M_{u,v}(a,b,c,d) = 2(a^2 - ab - b^2)q_1 q_2 - 2(c^2 - cd - d^2)p_1 p_2 + (p_1 q_2 - p_2 q_1)(-2ac + 2bd + ad + bc) \in \mathbb{Z}.$$
因此
$$2\xi_1 \xi_2' = M_{u,v}(a,b,c,d) - \varepsilon D \sqrt{5}, \qquad \Phi_{u,v}(\eta) = \left|\frac{\varepsilon M_{u,v}(a,b,c,d)}{D\sqrt{5}} - 1\right|.$$
在 $\mathbb{Q}(\sqrt{5})$ 中取域范数 $N(x + y\sqrt{5}) = x^2 - 5y^2$，立即得到一般有理端点的**范数同余方程**：
$$M_{u,v}(a,b,c,d)^2 - 5 D^2 = 4 N(\xi_1) N(\xi_2).$$
同时，对任意 $p\varphi + q \in \mathbb{Z}[\varphi]$，其域范数满足模 $5$ 完全分歧配方恒等式：
$$N(p\varphi + q) = -p^2 + pq + q^2 = -(p + 2q)^2 + 5(p + q)q,$$
从而 $5 \mid N(p\varphi + q) \iff 5 \mid (p + 2q)$。

### 2.2 $B=2$ 周期 10 模型的 $D=8$ Pell-范数同余刚性（引理 `lem:pell-b2-rigidity` (2)）

对于 $x = \frac{11}{2} - e = \frac{11 - 2e}{2}$，应用论文一定理 `thm:affine-window`（$A=11, B=2, C=-2$）得 $L = \max(B,|C|)^2 = 4$，$T = 2B|C| = 8$，且因 $Q_j$ 为奇数、$\gcd(P_j,Q_j)=1$，恒有 $G_j = \gcd(11Q_j - 2P_j, 2Q_j) = 1$。核对基本周期窗口 $W_6, \dots, W_{13}$（$m=1,2,3,4$ 时 $W_{2m+4} = [m+1, 1, 1, 1, 2]$，$W_{2m+5} = [m+2, 2, 1, 1, 1]$）及递推 $W_{j+8} = (b_j + 4, S_j)$（$j \ge 6$），无条件确立 $\frac{11}{2} - e$ 从下标 $8$ 起具有周期 10 的 Hurwitz 展开：
$$\frac{11}{2} - e = \bigl[2; 1, 3, 1, 3, 1, 1, 1, \overline{2, k, 2, 1, 1, 1, k, 1, 1, 1}_{k=1}^\infty\bigr],$$
其中每块含两处无界部分商 $a_{s_k} = k$（$s_k = 10k - 1$）与 $a_{t_k} = k$（$t_k = 10k + 4$）：
- 在第一处大商 $a_{s_k} = k$ 后紧跟四元组 $(2, 1, 1, 1)$，其在 $m = s_k + 1$ 处的完全商极限为 $u = [2; 1, 1, 1] = \frac{8}{3}$，$v = \lim_{k\to\infty} z_{s_k} = 0$（且该四元组内部各步的局部有理极限对分别为 $(8/3, 0)$、$(3/2, 1/2)$、$(2, 2/3)$、$(1, 3/5)$，不变量均为 $D = p_1 q_2 + p_2 q_1 = 8$）；
- 在第二处大商 $a_{t_k} = k$ 后紧跟四元组 $(1, 1, 1, 2)$，其在 $m = t_k + 1$ 处的完全商极限为 $u = [1; 1, 1, 2] = \frac{8}{5}$，$v = \lim_{k\to\infty} z_{t_k} = 0$（内部各步局部有理极限对分别为 $(8/5, 0)$、$(5/3, 1)$、$(3/2, 1/2)$、$(2, 2/3)$，不变量同样恒为 $D = 8$）。

对 $(u, v) = (8/q_1, 0)$（其中 $q_1 \in \{3, 5\}$，$p_1 = 8, p_2 = 0, q_2 = 1, D = 8$）：
$$\xi_1 = (8c - q_1 a)\varphi + (8d - q_1 b), \qquad \xi_2 = \gamma := a\varphi + b, \qquad \xi_1 \gamma' = m_{8,q_1}(a,b,c,d) - 4\varepsilon\sqrt{5},$$
其中
$$m_{8,q_1}(a,b,c,d) = q_1(a^2 - ab - b^2) - 8ac + 4ad + 4bc + 8bd \in \mathbb{Z}$$
满足范数恒等式与**模 $4$ 同余分解**：
$$m_{8,q_1}^2 - 80 = N(\xi_1) N(\gamma), \qquad m_{8,q_1} + q_1 N(\gamma) = 4(-2ac + 2bd + ad + bc).$$

由此立得三项核心刚性结论：
1. **奇偶刚性**：因 $|ad-bc|=1$，$\gcd(a,b)=1$，故 $N(\gamma) = -a^2 + ab + b^2$ 必为奇数；又 $q_1 \in \{3, 5\}$ 为奇数，模 $4$ 分解式右端为 $4$ 的倍数，故 $m_{8,q_1}$ 及 $m := \varepsilon m_{8,q_1}$ **必为奇整数**，且
   $$\Phi_{8/q_1, 0}(\eta) = \left|\frac{m}{4\sqrt{5}} - 1\right|.$$
2. **Pell $9^2 - 5\cdot 4^2 = 1$ 谱隙**：由 Pell 方程基本解 $\varphi^6 = 9 + 4\sqrt{5}$ 知 $(4\sqrt{5})^2 = 80 = 9^2 - 1$，故
   $$8 < \frac{44}{5} = 8.8 < 4\sqrt{5} = \sqrt{80} \approx 8.94427191 < 9.$$
   - 当 $m = 9$ 时，达到绝对极小值 $\frac{9}{4\sqrt{5}} - 1 \approx 0.006230589875$；
   - 对一切整数 $m \ne 9$（即 $m \le 8$ 或 $m \ge 10$），因 $9 - 4\sqrt{5} < 4\sqrt{5} - 8 < 10 - 4\sqrt{5}$，有
     $$\left|\frac{m}{4\sqrt{5}} - 1\right| \ge 1 - \frac{8}{4\sqrt{5}} = 1 - \frac{2}{\sqrt{5}} \approx 0.10557281;$$
   - 对一切**奇整数** $m \ne 9$（即 $m \le 7$ 或 $m \ge 11$），因 $4\sqrt{5} < 9 = \frac{7+11}{2}$，$4\sqrt{5}$ 距离 $7$（$1.94427$）严格小于距离 $11$（$2.05573$），故有
     $$\left|\frac{m}{4\sqrt{5}} - 1\right| \ge 1 - \frac{7}{4\sqrt{5}} \approx 0.21737621 < \frac{11}{4\sqrt{5}} - 1 \approx 0.22983739.$$
3. **极值点唯一性与模 $4$ 符号筛选**：
   若 $\Phi_{8/q_1, 0}(\eta) = \frac{9}{4\sqrt{5}} - 1$，则 $m = 9$，即 $m_{8,q_1} = 9\varepsilon$。代入范数恒等式得
   $$N(\xi_1) N(\gamma) = 9^2 - 80 = +1 \implies N(\gamma) \in \{\pm 1\}, \quad \sigma := \varepsilon N(\gamma) \in \{\pm 1\}.$$
   将 $m_{8,q_1} = 9\varepsilon$ 代入模 $4$ 同余分解式并乘以 $\varepsilon$（注意 $\varepsilon^2 = 1$）：
   $$9 + q_1 \sigma = 4\varepsilon(-2ac + 2bd + ad + bc) \equiv 0 \pmod 4.$$
   - 当 $q_1 = 5$ 时：$9 + 5\sigma \equiv 0 \pmod 4$ 唯一迫使 $\sigma = -1$（若 $\sigma = +1$ 则 $14 \not\equiv 0 \pmod 4$）。由 $\xi_1 + 5\gamma = 8(c\varphi+d)$ 及 $\xi_1/\gamma = \xi_1\gamma'/N(\gamma) = \sigma(9 - 4\sqrt{5}) = -(9 - 4\sqrt{5})$，得
     $$8(c\varphi+d) = (5 - 9 + 4\sqrt{5})\gamma = 4(\sqrt{5}-1)\gamma = \frac{8}{\varphi}\gamma \implies \eta = \frac{\gamma}{c\varphi+d} = \varphi.$$
   - 当 $q_1 = 3$ 时：$9 + 3\sigma \equiv 0 \pmod 4$ 唯一迫使 $\sigma = +1$（若 $\sigma = -1$ 则 $6 \not\equiv 0 \pmod 4$）。由 $\xi_1 + 3\gamma = 8(c\varphi+d)$ 及 $\xi_1/\gamma = +(9 - 4\sqrt{5})$，得
     $$8(c\varphi+d) = (3 + 9 - 4\sqrt{5})\gamma = 4(3-\sqrt{5})\gamma = \frac{8}{\varphi+1}\gamma \implies \eta = \frac{\gamma}{c\varphi+d} = \varphi + 1.$$

### 2.3 定理 `thm:golden-b2-exact` 的分歧位置分类闭合证明

设 $(\beta_n) \subset E_\varphi \setminus \{\beta_k^{(1)}, \beta_k^{(2)} : k \ge 1\}$ 满足 $h(\beta_n) \to \infty$ 且 $E_n := h(\beta_n)|x - \beta_n| \to L < 1 - \frac{7}{4\sqrt{5}}$。设 $m_n \to \infty$ 为 $\beta_n$ 与 $x = \frac{11}{2} - e$ 的首个连分数部分商分歧下标：

1. **情形 1A（$m_n \in \{s_k+1, s_k+2, s_k+3, s_k+4\}$，在第一处 $k$ 后的有界块 $(2,1,1,1)$ 内分歧）**：
   在 $m = s_k + 1$ 处应用 Bugeaud (2014) 式 (3.4)，其中 $T_{s_k+1} = \frac{8}{3} - \delta_k^{(1)}$（$0 < \delta_k^{(1)} = \frac{1}{3(3T_{t_k}+2)} \to 0^+$），$z_{s_k} \to 0^+$，$\beta_n = M_{s_k+1}(\eta_n)$，$\eta_n = [b_1; b_2, b_3, b_4, \dots] \in E_\varphi \cap (1, \infty)$。
   因 $m_n \le s_k + 4$，前四位 $(b_1,b_2,b_3,b_4) \ne (2,1,1,1)$，故 $\eta_n \ne \varphi + 1 = [2; \overline{1}]$。逐一核查四种前缀偏离：
   - $b_1 = 1 \implies \eta_n < 2 < \frac{13}{5}$；$b_1 \ge 3 \implies \eta_n > 3 > \frac{8}{3}$；
   - $(b_1, b_2 \ge 2) \implies \eta_n < \frac{5}{2} < \frac{13}{5}$；
   - $(2, 1, b_3 \ge 2) \implies \eta_n > [2; 1, 2] = \frac{11}{4} > \frac{8}{3}$；
   - $(2, 1, 1, b_4 \ge 2) \implies \eta_n < [2; 1, 1, 2] = \frac{13}{5}$。
   故恒有 $\eta_n > \frac{8}{3}$ 或 $\eta_n < \frac{13}{5}$，从而 $|T_{s_k+1} - \eta_n| \ge (1 - 15\delta_k^{(1)})|\frac{8}{3} - \eta_n|$。又由 Galois 纯周期连分数定理，一切 $\eta \in E_\varphi \cap (1, \infty)$ 均满足 $|\eta'| \ge |\varphi'| = \varphi - 1 > \frac{1}{2}$，故 $|\eta_n' + z_{s_k}| \ge (1 - 2z_{s_k})|\eta_n'|$。由引理 `lem:pell-b2-rigidity` (2)（`b2_case1_83_lower_bound`）得
   $$E_n \ge \frac{(1 - 15\delta_k^{(1)})(1 - 2z_{s_k})}{1 + 3z_{s_k}/8} \Phi_{8/3, 0}(\eta_n) \ge (1 - o(1))\left(1 - \frac{7}{4\sqrt{5}}\right).$$

2. **情形 1B（$m_n \in \{t_k+1, t_k+2, t_k+3, t_k+4\}$，在第二处 $k$ 后的有界块 $(1,1,1,2)$ 内分歧）**：
   在 $m = t_k + 1$ 处应用式 (3.4)，其中 $T_{t_k+1} = \frac{8}{5} - \delta_k^{(2)}$（$0 < \delta_k^{(2)} = \frac{1}{5(5T_{s_{k+1}}+2)} \to 0^+$），$z_{t_k} \to 0^+$，$\beta_n = M_{t_k+1}(\eta_n)$。因 $\beta_n \ne \beta_k^{(2)}$，有 $\eta_n \ne \varphi = [\overline{1}]$。对 $(b_1,b_2,b_3,b_4) \ne (1,1,1,2)$ 的五种前缀偏离：
   - $b_1 \ge 2 \implies \eta_n > 2 > \frac{8}{5}$；
   - $(1, b_2 \ge 2) \implies \eta_n < \frac{3}{2} < \frac{11}{7}$；
   - $(1, 1, b_3 \ge 2) \implies \eta_n > \frac{5}{3} > \frac{8}{5}$；
   - $(1, 1, 1, 1) \implies \eta_n = [1; 1, 1, 1, t] = \frac{5t+3}{3t+2} > \frac{8}{5} > T_{t_k+1}$（对一切尾商 $t > 1$，$\eta_n$ 与 $T_{t_k+1}$ 分居 $\frac{8}{5}$ 两侧，故 $|T_{t_k+1} - \eta_n| > |\frac{8}{5} - \eta_n|$）；
   - $(1, 1, 1, b_4 \ge 3) \implies \eta_n < [1; 1, 1, 3] = \frac{11}{7}$。
   故恒有 $\eta_n > \frac{8}{5}$ 或 $\eta_n < \frac{11}{7}$，从而 $|T_{t_k+1} - \eta_n| \ge (1 - 35\delta_k^{(2)})|\frac{8}{5} - \eta_n|$。由引理 `lem:pell-b2-rigidity` (2)（`b2_case1_85_lower_bound`）得
   $$E_n \ge \frac{(1 - 35\delta_k^{(2)})(1 - 2z_{t_k})}{1 + 5z_{t_k}/8} \Phi_{8/5, 0}(\eta_n) \ge (1 - o(1))\left(1 - \frac{7}{4\sqrt{5}}\right).$$

3. **情形 2（$m_n = s_k$ 或 $m_n = t_k$，在大商位置 $a_m = k$ 处直接分歧）**：
   此时 $T_m = k + r + o(1)$，$z_{m-1} = r + o(1)$，其中 $r = 3/8$（当 $m = s_k$）或 $r = 5/8$（当 $m = t_k$）。写 $\eta_n = Q_n + \theta_n$（$Q_n \in \mathbb{Z}_{\ge 1} \setminus \{k\}$，$\theta_n \in E_\varphi \cap (0, 1)$）。由高度二分律（`height_dichotomy`）：
   - 若 $\theta_n = \varphi - 1$（$h(\eta_n) = 2/\sqrt{5}, \theta_n' = -\varphi$）：
     - 在 $m = t_k$（$r = 5/8$）处，$Q_n = 1$ 对应 $[a_0; \dots, a_{s_k}, 2, 1, 1, 1, 1, \overline{1}] = \beta_k^{(1)}$（已排除）；
     - 在 $m = s_k$（$r = 3/8$）处，$Q_n = 1$ 对应 $[a_0; \dots, a_{t_{k-1}}, 1, 1, 1, 2, \overline{1}]$，极限恰为 $\frac{2}{\sqrt{5}}|1 - \varphi + \frac{3}{8}| = 1 - \frac{7}{4\sqrt{5}}$（`b2_case2_sk_Q1_limit`）；
     - 对 $2 \le Q_n \le k - 1$，由凹二次函数下界（`b2_case2_sub1_quadratic_ge`），在端点 $Q_n = 2$ 与 $Q_n = k - 1$ 处达到极小，极限为 $\frac{2}{\sqrt{5}}(2 - \varphi + r) \ge \frac{15}{4\sqrt{5}} - 1 \approx 0.67705 > 1 - \frac{7}{4\sqrt{5}}$；
     - 对 $Q_n \ge k + 1$，极限 $\ge \frac{2}{\sqrt{5}}(\varphi - r) \ge 1 - \frac{1}{4\sqrt{5}} \approx 0.88820 > 1 - \frac{7}{4\sqrt{5}}$。
   - 若 $\theta_n = 2 - \varphi$（$h(\eta_n) = 2/\sqrt{5}, \theta_n' = 1 + \varphi$）：在 $Q_n = 1$、$2 \le Q_n \le k - 1$、$Q_n \ge k + 1$ 各处极限均 $\ge \frac{15}{4\sqrt{5}} - 1 > 1 - \frac{7}{4\sqrt{5}}$。
   - 若 $\theta_n \notin \{\varphi - 1, 2 - \varphi\}$：则 $h(\eta_n) \ge 2\sqrt{5}$ 且 $\theta_n' > -1$，由凹二次界（`b2_case2_sub3_quadratic_ge`）得 $E_n \ge 2\sqrt{5}\cdot \frac{3}{8} - o(1) = \frac{3\sqrt{5}}{4} - o(1) \approx 1.67705 > 1 - \frac{7}{4\sqrt{5}}$。

综上，所有非极值序列的 $\liminf$ 均 $\ge 1 - \frac{7}{4\sqrt{5}}$，定理证毕。
