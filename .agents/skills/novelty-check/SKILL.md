# Novelty Check（新颖性与先行文献对照）

严格执行 `AGENTS.md` 的引用纪律，核查特定数学结果、常数或方法的新颖性及引文准确性。

## 执行流程

1. **拆解待核结果**
   - 将待评估的定理、方法或常数拆分为可独立检索的数学陈述（包含精确条件、对象与结论）。

2. **构造多路检索式**
   - 为每个待核结果构造检索式：`数学关键词 + 作者 + 年份`（中英文术语、经典同义表述、arXiv/期刊/zbMATH/MathSciNet 线索），并经 arxiv 与 paper-search MCP 双源实际执行检索。

3. **严格采信原则**
   - 书目信息（作者、期刊、卷、页、年份、DOI、定理编号、常数）**只采信实际打开核对过的原始页面或全文**。
   - 任何未实际打开核对到的字段，一律填写「**未核到**」，严禁凭记忆补全或编造。

4. **逐项给出核查结论**
   - **有先例**：给出实际核对到的文献出处、定理编号及与本文结果的精确异同。
   - **无先例**：必须明确标注为「**负搜索未找到先例**」，并完整说明检索式、数据库/来源与时间覆盖范围，禁止宣称“已证明不存在先例”。
   - **未核实**：明确注明缺少哪份全文或页面权限/字段。

5. **引用错误单独标红（醒目标出）**
   - 若发现论文中存在作者顺序、题名、期刊卷号、页码、年份、DOI、定理编号或常数转述不符，**单独分段醒目标出**（如 `【引用错误】`），写明原文写法与原始页面核对结果。

## 输出格式
遵循 `AGENTS.md`：先给**一句总判断**，再给对照表（`结果 | 类别 | 核查状态 | 与已有文献关系 | 依据`），并单列【引用错误】清单。
