# Proof Reasoning（数学推理与证明检验）

对证明草稿、猜想或候选路线进行对抗性逐行审查、边界反例测试与可证伪计算检验。

## 执行流程

1. **复述命题与证明骨架**
   - 先用自己的话精确复述待检命题的量词顺序、假设前提、结论，以及证明的核心骨架。

2. **逐步检查每个蕴含，标出跳步**
   - 逐行审查每一步推导：不等号方向、量词交换、可和性/极限交换、整除与非零条件、特例边界。
   - 多步或复杂证明用 sequential-thinking MCP 工具逐蕴含展开检查，防止多个跳步被一次叙述掩盖。
   - 禁止使用“显然/同理/易见”跳过关键步；所有未展开或缺乏依据处必须显式标为 `[跳步]` 或 `[缺口]`。

3. **主动构造反例与极端情形**
   - 测试退化情形与小参数（如 $n=0,1,2$、边界等号、有理数/代数数特例）。
   - 对针对 $\pi$ 或 $e+\pi$ 的通用论证，主动用已知满足相同通用条件的替代点（如 $x=A/B-e$ 或给定截断模型）检验该论证是否同样适用；若适用，则该路线无法区分真实 $\pi$。

4. **难度等价判定**
   - 若结论本质上只是原问题的等价改写或同族换靶（未降低核心难度），必须直说「**难度未降**」，并指出为何未跨过障碍。

5. **可证伪的下一步与计算验证**
   - 给出可证伪的下一步检验（具体数值实验或待证中间引理）。
   - 凡涉及数值、常数、界或计数，必须按 `AGENTS.md` 计算纪律编写 Python/`mpmath` 高精度脚本实测，并将脚本与输出保留在 workspace 内供复查，禁止心算给数。

## 输出格式
遵循 `AGENTS.md`：先给**一句总判断**，给出对照表（`结果 | 类别 | 核查状态 | 与已有文献关系 | 依据`），随后列出逐行检验、反例测试结果与下一步可证伪实验。
