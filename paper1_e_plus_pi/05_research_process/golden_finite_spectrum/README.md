# 有理平移的黄金比轨道有限判定

2026 年 11 月 20 日。主稿定理 8.25，推论 8.26。

## 证明与结果

- 对任意既约 A/B，给定正有理阈值 H，可以完整枚举 A/B-e 的黄金比轨道中从高度趋于无穷的序列得到、且落在 [0,H] 的归一化误差极限。
- 首次失配位于有界后缀时，复用原稿的范数反演。首次失配位于增长首项时，把候选首位在增长首项的一半处分割。左侧迫使首位有界，右侧迫使首位相对增长首项的偏移有界；两侧分别得到有限的尾项集合。两类极限都由固定尾项的轨道点序列达到。
- 精确算术重现 B=1 至 4 的已有结果，并给出 B=5 的四个既约余类、B=6 的两个既约余类，以及 22/7-e 的最小与次小极限。B=7 的数字仅针对 22/7-e。
- 全定理以纸面证明给出。Lean 只核验关键的三个实数不等式。三个声明仅依赖基础公理 propext、Classical.choice、Quot.sound，无 sorryAx。底层 Möbius 公式使用原稿引用的 Bugeaud 原文式 (3.4)，有关已有精确算法的优先权尚未做全面检索。
- 原问题 e+π 的无理性依然开放。一般仿射模型中可能混有单项窗口，当前有限性证明所需的正距离下界在该情形未建立。

## 复现

1. 运行 python golden_finite_spectrum.py 可验证完整基准组。运算、选值和比较均使用整数、有理数及二次域的精确算术；打印的小数用于阅读。
2. 运行 python golden_finite_spectrum.py 22 7 --cap 1/100 --all 可枚举该模型在指定阈值以内的极限。
3. 从现有 epi_formal 工程根目录执行 lake env lean -j 1 <GoldenHeadCutoff.lean 的绝对路径>。本机依赖提示有本地改动。
4. 编译主稿并复核结果时，参见[核查与变更记录](核查与变更记录.md)。
