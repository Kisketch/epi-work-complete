# Round 2 C　约分公式、锁定窗口的周期性

## 一、逐素数约分（无条件纸面证明）

沿用命题 8.3。令 Q=q/g、D=d/g、V=DP+Qp、U=gQD。由于 (Q,D)=(P,q)=(p,d)=1，任一整除 Q 或 D 的素数不整除 V，因此 h=gcd(U,V)=gcd(g,V)，h|g。对素数 ℓ 写 a=vℓ(q)、b=vℓ(d)。若 a≠b 或 min(a,b)=0 则 vℓ(h)=0。若 a=b=t>0，则 vℓ(h)=min(t,vℓ(V))。更具体地，对 1≤i≤t，ℓ^i|h 当且仅当 p≡−DP Q⁻¹ mod ℓ^i。这是对全部输入的等价分类。两指数相同时并不保证发生约分；它还取决于分子。本项目的 q 始终奇，故 ℓ=2 永无贡献。

## 二、有理假设下的精确锁定

设 e+x=A/B，A、B 整数且 B>0，x 无理。设 Q_j、P_j 为文中的 Hermite 分母分子，H_j=⌊Q_j√j⌋。令 k(j) 为 x 的最后一个收敛分母不超过 H_j 的指标，整数部分收敛分数指标为 0。以下对充分大 j 都成立。

写 p*/s 为该收敛分数。由下一个分母 >H_j，|sx−p*|<1/(H_j+1)。命题 8.1 证明中的整数恒等式（直接把 π 换成 x）表明一旦 j>(3B/2)^2，有 A Q_j s−B(P_j s+Q_j p*)=0。因此
(p*,s)=((A Q_j−B P_j)/M_j, B Q_j/M_j)，其中 M_j=gcd(AQ_j−BP_j,BQ_j)。
M_j | B gcd(AQ_j−BP_j,Q_j)=B gcd(B,Q_j) | B²。锁定后的残差 sx−p*=−s(Q_j e−P_j)/Q_j，故 k(j) 与 j 奇偶相反。由于 Q_{j+1}/Q_j→∞、M_j|B²，锁定分母最终严格递增。

设同号前驱是 p/d，即指标 k(j)−1。由相邻行列式 |p*d−sp|=1 和命题 8.3 的定义直接得到 B|L_j|=M_j/(g h)，又 gh s/Q_j=B g h/M_j。由 Q_j | B s 且 gcd(d,s)=1，g|B。因而同号分母的 g 无界本身就足以证无理。对于真实 π 尚无无界性证明。

## 三、连续窗口中新增收敛分母数最终周期（条件定理，独立推导）

令 v_m=(p_m,d_m)，m=k(j)，r=k(j+1)−k(j)>0。奇偶锁定保证 r 为奇数。
对锁定向量应用 det，使用 |P_j Q_{j+1}−P_{j+1}Q_j|=2，得到

Δ_j=|det(v_m,v_{m+r})|=2 B²/(M_j M_{j+1}).

在 unimodular 基 v_m,v_{m−1} 下，v_{m+r}=C v_m+Δ_j v_{m−1}。两系数为正互素整数，且递推给出 C/Δ_j=[a_{m+1};…;a_{m+r}]。模 Δ_j 有 v_{m+r}≡C v_m。因 v_m 本原，这条双坐标同余唯一确定 C mod Δ_j。终止连分数允许末位为 1：非整数正有理数只有两种正规终止表示，长度相差 1；其首位后的列表由分数部分和长度奇偶指定。整数在此情形选择奇数长度为 1 的表示。因此 r 完全由 (Δ_j, C mod Δ_j) 确定。这里须取 m 足够大，避免 m=0 的初始化约定。

取固定模数 T=2B²。由 gcd 性质可由原向量 (AQ_j−BP_j,BQ_j) mod B² 读出 M_j（把这两坐标与 B² 三者取 gcd）。因 M_j Δ_j=2B²/M_{j+1} | T，可由原向量 mod T 算归一化向量 v_m mod Δ_j，同样可读 v_{m+r} mod Δ_j。Hermite 二阶递推 X_{j+1}=(4j+2)X_j+X_{j−1} 在有限状态 (j,P_{j−1},P_j,Q_{j−1},Q_j) mod T 上是双射：从输出先复原 j，然后由减法复原两个前一项。因此状态周期，Δ_j、C mod Δ_j、r_j 都最终周期。此证明只取有限状态，不要求从巨大 B 数值枚举。可对每个剩余类额外得到首位以外的完整有界部分商串。

推论：存在有理数 ρ≥1，使 k(j)=ρj+O_B(1)（固定 A,B）。任意 n 在 k(j)≤n<k(j+1) 之间时，锁定分母的上下界和 log Q_j=j log j+O(j) 给出 log d_n = (1/ρ)n log n + O_{A,B}(n)。因此只需证明真实 π 的窗口计数不是最终周期，即可证原问题；证明增长系数不存在或不为有理数 1/ρ 也足够。这些尚非真实 π 的无条件定理。有限样本不排除长前周期或大周期。该结论是对本项目指标的有限状态描述；未认定文献首创。

## 四、独立计算

verify.py 用 Python 标准库 Fraction，对反正切交错余项、指数正项尾项、相邻连分数前缀进行精确包围。已逐条检验 2≤j≤60 的真实 π 及三个对照 6−e、17/3−e、43/7−e，共 236 行，输出 certified.csv。对照组 j≥B² 的锁定、gh 关系和相邻锁定行列式均以整数断言核查（纸面阈值以上当然覆盖）。真实 π 的 59 行 h 都是 1，不能据此外推任何渐近结论。构造例 q=d=3、P=1、p=2 给 h=3，说明 h=1 并非一般恒等式。纸面结论均未做 Lean 核验。

建议下个严格目标：对真实 π 证明窗口计数序列对每个候选周期 T 均有任意远的错配。排除每个有限前缀都不能完成这个量词要求。可先形式化有限状态的 C/Δ 连分数长度由余数和奇偶唯一确定这条抽象引理。
