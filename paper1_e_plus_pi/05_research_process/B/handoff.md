# B 组研究札记 · 阶乘尾项能否排除有理性？

## 首页｜最强已证命题与剩余估计

记 \(u_n=\{-n!\pi\}\)，\(\{x\}=x-\lfloor x\rfloor\)，\(\|x\|=\min_{j\in\mathbb Z}|x-j|\)。以下有限和 \(S_{n,m}\) **已经乘过 \(n!\)**，Machin 公式的两支各保留 \(m\) 项。

**命题 B1（完整有限和的分母障碍）。** 对任何正整数截断序列 \(m=m(n)\)，若 \(|n!\pi-S_{n,m}|=O(1/n)\)，则对所有充分大的 \(n\)，完整有限和的既约分母含有一个严格大于 \(n\) 的素因子，其指数恰为 1。结论也适用于任一无界子序列，只需沿该子序列满足同样的误差界。因而“让部分和成为整数，同时把尾项压到 \(1/n\) 量级”在这种截断下无法成功，即使容许两支以及全部指标相互约分。

**命题 B2（固定偏差阈值）。** 或者 \(nu_n\to1\)，或者 \(\limsup |nu_n-1|\ge1\)。因此题目中的 \(\varepsilon\) 可预先取 \(1/2\)，无需猜测一个与 \(\pi\) 有关的微小常数。此命题本身没有判定 \(\pi\) 属于哪一种情形。

**仍需证明的最小分布估计（等价的单一算术问题）。** 对 \(n\ge2\)，固定截断
\[
 m_n=\min\{m\ge1:(2m+1)5^{2m+1}\ge16\,n!n^2\}.
\]
令 \(P_n/Q_n=S_{n,m_n}\) 为既约分数，\(Q_n>0\)。只差证明
\[
 \boxed{\quad\forall N\ \exists n\ge\max(N,2):\
 \min_{j\in\mathbb Z}|nP_n+Q_n-jnQ_n|\ \ge Q_n/2.\quad} \tag{★}
\]
该目标与排除原极限等价。它只问一个显式整数的最小绝对剩余，不要求等分布、正密度或固定半区命中。B1 控制 \(Q_n\) 的素因子；(★) 还需要控制分子的位置。下文给出证明和小指标证书。

## 1　逐字核对与负号

相对于 epi_work，源码是 `epi_formal/EpiFormal/FactorialCriterion.lean`。其中第 27、30 行定义（函数体逐字）和第 509–511 行声明如下。

```lean
noncomputable def uFrac (n : ℕ) : ℝ := Int.fract (-(n.factorial : ℝ) * Real.pi)
noncomputable def tFrac (n : ℕ) : ℝ := Int.fract ((n.factorial : ℝ) * Real.exp 1)

theorem factorial_criterion :
    (∃ q : ℚ, Real.exp 1 + Real.pi = q) ↔
    Tendsto (fun n : ℕ => (n : ℝ) * uFrac n) atTop (nhds 1) := by
```

`Int.fract` 取值在 \([0,1)\)。指标是全体自然数（含 0），左侧是存在有理数，右侧是对每个 \(\eta>0\) 存在 \(N\)，对所有 \(n\ge N\) 有 \(|nu_n-1|<\eta\)。其否定为存在固定 \(\eta>0\)，对每个 \(N\) 都存在 \(n\ge N\) 使偏差 \(\ge\eta\)。文件中 `tFrac_eq_tail` 的前提为 \(1\le n\)，`tFrac_bounds` 的前提为 \(2\le n\)，最终定理没有起始指标假设。已在原工程执行 `lake env lean EpiFormal/FactorialCriterion.lean`，退出码 0；最终定理的公理输出为 `[propext, Classical.choice, Quot.sound]`。本札记 B1、B2 及 (★) 的归约为下文的纸面证明。

从 \(e=\sum_{k=0}^{\infty}1/k!\) 出发，写成
\[
 n!e=J_n+T_n,\qquad J_n=\sum_{k=0}^{n} n!/k!\in\mathbb Z,\quad
 T_n=\sum_{j=1}^\infty\frac1{(n+1)\cdots(n+j)} .
\]
对 \(n\ge1\)，首项给出严格下界；每项至多为 \((n+1)^{-j}\)，从 \(j=2\) 起严格，于是
\[
 \frac1{n+1}<T_n<\sum_{j=1}^{\infty}(n+1)^{-j}=\frac1n .
\]
所以 \(\{n!e\}=T_n\)，且 \(n/(n+1)<nT_n<1\)。\(n=0\) 时 \(T_0=e-1>1\)，不能在此处把尾和认作分数部分。

若 \(e+\pi=A/B\)，取 \(A\in\mathbb Z,B\ge1\) 为整数。当 \(n\ge B\) 时 \(B\mid n!\)，故 \(K_n=n!A/B\) 为整数。移项得到
\[
 -n!\pi=n!e-K_n,\qquad u_n=\{n!e\}=T_n,\qquad nu_n\longrightarrow1.
\]
负号来自移项。换用 \(x=6-e\) 时，对每个 \(n\ge1\) 都有 \(\{-n!x\}=T_n\)、\(\{n!x\}=1-T_n\)。例如 \(n=2\) 时前者为 \(2e-5\)，后者为 \(6-2e\)；前者乘 \(n\) 趋于 1，后者乘 \(n\) 趋于无穷。主稿 `第一阶段_e_plus_pi.tex` 第 400–405 行据此指出：因 \(n!\pi\notin\mathbb Z\)，若 \(\{n!\pi\}\le1/2\) 无穷多次，则相应 \(nu_n\ge n/2\)，足以排除该极限。

## 2　选择展开式与精确分母

| 候选 | 乘 \(n!\) 后的单项分母来源 | 截断比较 |
|---|---|---|
| Gregory 公式 \(4\arctan 1\) | 奇数 \(d\)；既约分母 \(d/\gcd(d,4n!)\) | 截至 \(d=2m-1\)，尾项绝对值至少 \(2n!/(2m+1)\)，因为余项积分中 \(1/(1+t^2)\ge1/2\)。达到 \(O(1/n)\) 需 \(m\) 至少为 \(nn!\) 量级。 |
| Machin 公式 \(16\arctan(1/5)-4\arctan(1/239)\) | 奇数 \(d\) 与 \(5^d,239^d\) | 尾项按奇数指数几何衰减，且两支之差仍能证明严格下界，故采用此式。 |

恒等式也可直接核对。设 \(\theta=\arctan(1/5)\)。两次倍角得 \(\tan(2\theta)=5/12,\ \tan(4\theta)=120/119\)。因 \(0<2\theta<\pi/4\)，有 \(0<4\theta<\pi/2\)，又 \(\tan(4\theta)>1\)。差角公式给出 \(\tan(4\theta-\pi/4)=1/239\)，由所在象限得所述公式。

设 \(d=2k+1\)。定义
\[
 S_{n,m}=n!\sum_{k=0}^{m-1}\frac{(-1)^k}{d}
       \left(\frac{16}{5^d}-\frac{4}{239^d}\right).
\]
每个 \(k\) 的两支（\(a,c\) 依次为 \((5,16),(239,4)\)）的既约正分母恰为
\[
 \frac{d a^d}{\gcd(d a^d,c\,n!)}.
\]
相同指标两支合并，置 \(D_d=d\,5^d239^d,\ H_d=16\,239^d-4\,5^d\)，既约分母恰为 \(D_d/\gcd(D_d,n!H_d)\)。整个有限和若需精确分母，可取 \(L=\operatorname{lcm}_{k<m}D_{2k+1}\)，\(U=n!\sum_{k<m}(-1)^k H_d(L/D_d)\)，则 \(S=U/L\)，其既约分母为 \(L/\gcd(L,U)\)。这避免把各项分母的最小公倍数误作最后的既约分母。

## 3　同一截断的双侧余项与控制尺度

置 \(s=2m+1\) 为首个舍弃的指数。有限几何恒等式对 \(1/(1+t^2)\) 展开至第 \(m\) 项，积分得每支余项为 \((-1)^m I_a\)，其中
\[
 I_a=\int_0^{1/a}\frac{t^{s-1}}{1+t^2}\,dt,\qquad
 \frac{a^2}{a^2+1}\frac1{s a^s}<I_a<\frac1{s a^s}.
\]
设 \(R=n!\pi-S_{n,m}\)，\(A=n!/(s5^s)\)。于是
\[
 (-1)^mR=n!(16 I_5-4 I_{239}),\qquad
 15 A<(-1)^m R<16 A. \tag{1}
\]
下界来自 \(16(25/26)-4(5/239)^s>15\)；上界由 \(I_{239}>0\) 得出。这还排除了两支**同长度**余项相消到更高精度的可能。

首页的 \(m_n\) 存在，定义立即给出 \(|R|<1/n^2\)。下文计算 \(P_n/Q_n\) 时始终取这个 \(m_n\)。此选择使 \(n|R|<1/n\)，在放大 \(n\) 倍后误差仍趋于零。

## 4　大素因子为何在完整有限和中保留（B1）

1. 设沿无界指标 \(|R|\le C/n\)，记 \(D=2m-1=s-2\) 为最后保留的指数。若 \(D\le2n\)，则 (1) 给出 \(|R|>15 n!/((2n+2)5^{2n+2})\)。右边趋于无穷：相邻项之比为 \((n+1)(2n+2)/(25(2n+4))\to\infty\)。故沿该指标最终 \(D>2n\)。
2. 对 \((D-1)/2\) 用伯特兰定理，取素数 \(D/2<p\le D\)。充分大时 \(p>n\) 且 \(p>317\)。在 \(1,3,\ldots,D\) 中，被 \(p\) 整除的指标恰有 \(d=p\)，因为 \(2p>D\)。
3. 对 \(d=p\)，有 \(p\nmid n!5^p239^p\)。费马小定理给出 \(H_p\equiv16\cdot239-4\cdot5=3804=2^2\cdot3\cdot317\pmod p\)，非零。故这一对合并项的既约分母恰含一个 \(p\)。对所有 \(d\ne p\)，分母 \(D_d\) 与 \(p\) 互素。
4. 把其余项合为 \(b/c\)，其中 \(p\nmid c\)，把特殊项写成 \(a/(ph)\)，其中 \(p\nmid ah\)。再通分，分子 \(ac+bph\equiv ac\not\equiv0\pmod p\)。于是 \(p\) 在最终既约分母中也恰出现一次。实际上，这对每个 \(p\in(D/2,D]\) 且 \(p>\max(n,317)\) 都成立。例：\(n=400,\ m_n=624,\ D=1247,\ p=631,\ H_p\equiv18\bmod631\)。

若仅想逐项清分母，在 \(d=D\) 的 5 支已经需要 \(D+v_5(D)\le v_5(n!)=\sum_{j\ge1}\lfloor n/5^j\rfloor<n/4\)。这与第 1 步的 \(D>2n\) 冲突。第 2–4 步进一步排除了“个别项虽有分母，整个和或许是整数”的解释。这里的结论限于 Machin 两支同步截断和整性策略；大分母本身仍然可以对应任何很靠近指定窗口的剩余。

伯特兰定理的表述与证明可见 [Stanford 数论讲义](https://math.stanford.edu/~ksound/Math155W10/Bertrand.pdf)。

## 5　跨整数边界、固定阈值与 (★)

设 \(z_n=nu_n\)，\(c_n=(n+1)u_n-u_{n+1}=\lfloor(n+1)u_n\rfloor\in\mathbb Z\)。若 \(\limsup |z_n-1|<1\)，存在 \(\delta>0\) 使 \(\delta\le z_n\le2-\delta\) 最终恒成立。因此 \(u_n\to0\)，且 \(c_n-z_n=u_n-u_{n+1}\to0\)。充分大时 \(0<c_n<2\)，只能 \(c_n=1\)。直接移位尾和得 \((n+1)T_n-T_{n+1}=1\)。从共同起点 \(N\ge2\) 连减并迭代：
\[
 u_N-T_N=\frac{N!}{j!}(u_j-T_j),\qquad j\ge N.
\]
两分数都在 \((0,1)\)，令 \(j\to\infty\) 得 \(u_N=T_N\)，递推再得对所有 \(n\ge N\) 相等。故 \(nu_n\to1\)。取逆否即得 B2。

为精确处理跨整数，定义
\[
 D_n^*=n\|-n!\pi-1/n\|,\qquad E_n=n\|-S_{n,m_n}-1/n\|.
\]
到整数集合的距离为 1-Lipschitz 函数，因此 \(|D_n^*-E_n|\le n|R|<1/n\)，包括跨整数情形。若原极限成立，\(D_n^*\le|z_n-1|\to0\)。反之，若 \(\limsup D_n^*<1\)，取 \(\limsup D_n^*<c<1\)。对充分大的 \(n\)，半径 \(c/n\)、中心 \(1/n\) 的区间完全落入 \((0,1)\)，故 \(D_n^*\le c\) 蕴含 \(|z_n-1|\le c\)。应用 B2 即得原极限成立。因此原极限不成立时 \(\limsup E_n=\limsup D_n^*\ge1\)；原极限成立时 \(E_n\to0\)。又
\[
 E_n=\frac1{Q_n}\min_{j\in\mathbb Z}|nP_n+Q_n-jnQ_n|,
\]
所以 \(E_n\ge1/2\) 无穷多次恰等价于排除原极限。这证明了首页对 (★) 的归约。

## 6　小指标有理证书与复核

为直接包围 \(u_n\)，取 \(I\) 的两端为 \(-S-(-1)^m15A,\ -S-(-1)^m16A\)，排序得 \(l<h\)。由 (1)，\(-n!\pi\in(l,h)\)。若 \(\lfloor l\rfloor=\lfloor h\rfloor=a\)，则 \(n(l-a)<nu_n<n(h-a)\)。若跨一个整数 \(b\) 且两端非整数，模 1 后要分别保留 \((\{l\},1)\) 和 \([0,\{h\})\)；原数无理可另删 0。若宽度超过 1，这两段可能重叠；跨多个整数时保守取整个 \([0,1)\)。

| \(n\) | \(m_n\) | \(nu_n\) 的严格外包区间 |
|---:|---:|---:|
| 2 | 1 | (1.426, 1.438) |
| 3 | 2 | (0.450, 0.452) |
| 4 | 2 | (2.404, 2.411) |
| 5 | 3 | (0.043, 0.045) |
| 6 | 3 | (0.315, 0.324) |
| 10 | 6 | (5.785, 5.788) |
| 20 | 15 | (10.186, 10.187) |
| 50 | 48 | (32.937, 32.939) |
| 100 | 115 | (27.406, 27.408) |

实际跨界例：刻意将 \(n=5\) 改用 \(m=1\)，可得 \(S=120(16/5-4/239)\)、\(A=120/375\)，两端的下取整分别为 \(-378,-377\)。直接对两个端点取分数部分再按大小排序会选错圆弧。回到同一个 \(m_5=3\)，即可严格认证表中区间。

下列 Python 代码只使用整数与既约有理数，表内端点按千分位向外取整。有限例子检测符号和区间实现；无限子序列仍取决于 (★)。

```python
from fractions import Fraction as F
from math import factorial

def certificate(n, m=None):
    f = factorial(n)
    if m is None:
        m = 1
        while (2*m+1)*5**(2*m+1) < 16*f*n*n:
            m += 1
    s = 2*m+1
    S = sum((-1)**k * f * (F(16, d*5**d) - F(4, d*239**d))
            for k in range(m) for d in [2*k+1])
    A = F(f, s*5**s)
    ends = sorted(-S - (-1)**m * c*A for c in (15,16))
    lo, hi = ends
    a, b = lo//1, hi//1
    if a != b:
        return m, "wrap", a, b
    # 向外取整，以千分之一为单位输出 n 倍分数部分的严格包围。
    return m, (1000*n*(lo-a))//1, -((-1000*n*(hi-a))//1)

for n in [2, 3, 4, 5, 6, 10, 20, 50, 100]:
    print(n, certificate(n))
for n in range(2, 30):
    for m in range(1, 10):
        v = certificate(n,m)
        if len(v)==4 and v[3]-v[2]==1:
            print("cross", n, v)
            raise SystemExit
```
