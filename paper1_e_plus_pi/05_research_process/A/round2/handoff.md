# A 第二轮：有理仿射关系强迫部分商的离散斜率

**核验状态：纸面证明。** 针对 π 的奇偶重合或偏移无界性仍未证出。以下结果对每个固定有理仿射关系给出严格的必要条件，并无条件构造 1,e,x 线性无关的显式反模型。

## 1. 窗口的末收敛分数

取 Euler 展开 [2;1,2,1,1,4,1,1,6,…] 中紧邻 2j 之前的收敛分数 P_j/Q_j。设 H_j=⌊Q_j√j⌋。对无理数 x 记其收敛分数 p_i/d_i（i 从 0 开始），k(j)=max{i:d_i≤H_j}。在原始连续两个分母相同的起始情形仍取末指标；下述断言均针对充分大的 j。严格计数恒等式是
  # {i:H_j<d_i≤H_{j+1}}=k(j+1)−k(j)。
左端开右端闭，故 d_i 正好等于某个 H_j 也不改变等式。

**仿射刚性命题。** 若 x=(A+C e)/B，A,C 为整数、C≠0、B 为正整数，记 q=Q_j、P=P_j、G_j=gcd(Aq+CP,Bq)（取正）。则对所有充分大的 j，
\[
 (p_{k(j)},d_{k(j)})=((Aq+CP)/G_j,Bq/G_j),\qquad G_j\mid B|C|.
\]
证明：gcd(Aq+CP,q)=gcd(C,q) 因为 P 与 q 互素。逐素数取赋值，gcd(N,Bq) 整除 B gcd(N,q)，故整除 B|C|。候选既约分数 u/d 满足 d x−u=Cδ_j/G_j，δ_j=qe−P，|δ_j|<1/(2jq)。因此 d|d x−u|<B|C|/(2j G_j²)<1/2，Legendre 判据使其成为收敛分数。d≤Bq≤H_j 最终成立。若 s 为其下一分母，标准误差恒等式给 1/|d x−u|=s+θd，0<θ<1，从而 s>2jqG_j/|C|−Bq/G_j>H_j 最终成立。由此锁定末指标，无需为 π 假设任何分布律。

**部分商必要条件。** 收敛分数误差恒等式给
\[
 1/(Q_j|\delta_j|)=2j+\rho_j,\quad
 1/(d_{k(j)}|d_{k(j)}x-p_{k(j)}|)=a_{k(j)+1}(x)+\sigma_j
\]
且 0<ρ_j,σ_j<2（完整商的分数部分加上前后分母之比）。代入上式得
\[
 a_{k(j)+1}(x)=\frac{2G_j^2}{B|C|}\,j+
                  \frac{G_j^2}{B|C|}\rho_j-\sigma_j .
\]
故斜率只能落在固定有限集合中，余项一致有界。甚至 G_j 周期：置 M=B|C|，G_j=gcd(AQ_j+C P_j,BQ_j,M)。模 M 的状态为 j 及 P,Q 的两相邻坐标；每一步 j 加一且递推 (u,v)→(v,(4j+2)v+u) 可逆，有限状态给周期。

**相邻窗口。** 令 N_j=k(j+1)−k(j)。下述等式是不同分母之间的行列式，不是相邻 CF 步的行列式：
\[
 |p_{k(j+1)}d_{k(j)}-p_{k(j)}d_{k(j+1)}|
 =\frac{2 B|C|}{G_jG_{j+1}}.
\]
用 |P_{j+1}Q_j−P_jQ_{j+1}|=2 清分母即得。末分母 BQ_j/G_j 最终严格增长。相距 N≥1 步的收敛分数行列式等于中间部分商 a_{k+2},…,a_{k+N} 的连续子式，空列取 1；故至少 F_N（F_1=F_2=1）。于是 F_{N_j}≤2B|C|。特别，任何 x 的窗口新增分母数若无界，则 1,e,x 在 Q 上线性无关（假设 x 无理）。若 C<0，则 d x−u 与 δ_j 符号相反，故 k(j) 与 j 异奇偶，N_j 必为奇数。对于实际 π，上述“无界”和“偶数计数无穷多”仍待证明。

## 2. 显式反模型：恒定窗口计数且有不受限的次线性偏移

基准 6−e 的展开为 [3;3,1,1,4,1,1,6,1,1,…]，由 1−[0;1,z]=[0;z+1] 直接从 e 的展开得到（z 为对应完整商）。其指标 3j−3 处的收敛分母为 Q_j：j=1,2 给 1,7，其余也是反射分数 6−P_j/Q_j 保留分母，由对截断级数同施反射即可验证。

构造无理数 x*，仅把上述展开中指标 3j−2 处的 2j（j≥2）换成 2j+u_j，其中 j 是 2 的幂时 u_j=⌊√j⌋，其余为零。整个正整数连分数无限，故 x* 无理。各有限分母是部分商的非负系数多仿射连续子式。把一个数字 a 增加 u≥0 会让分母增至多 1+u/a 倍且不会减小。由于
\[
 K=\prod_{m\ge1}(1+u_{2^m}/(2\cdot 2^m))<\infty ,
\]
所有 j 的分母满足 Q_j≤d_{3j−3}(x*)≤K Q_j。下一分母至少 2j Q_j（j≥2）。故最终 k(j)=3j−3，窗口计数恒为 3，末指标始终与 j 异奇偶。甚至相邻窗口的行列式恒为 2，因为两颗内部部分商都是 1，其连续子式为 2。

但是 1,e,x* 线性无关。若 x* 有仿射表示，则 a_{k(j)+1}/(2j)=1+u_j/(2j)→1。上节给 G_j²/(B|C|)→1，这个数只能取有限多个值，故最终恰等于 1，进而 u_j 一致有界。沿 j=2^m 它无界，矛盾。这排除了每个有理仿射关系，包括 e+x* 为有理数的可能。

这一构造说明：奇偶重合、窗口计数无界均是充分条件，任一都不是必要条件；连续子式的有限性、周期性和奇偶性三者合在一起仍不足以判定某个具体数。对真实 π，可检测独立的必要条件：若下一部分商/2j 在某子列趋于 1、但下一部分商−2j 在同一子列无界，则 1,e,π 线性无关。此命题只是充分条件，未证 π 满足它。

## 3. 有界窗口增量的精确维数（纸面）

设 Δ_j=k(j+1)−k(j)。在 [0,1] 的无理数中，Δ_j 最终有界的集合 Hausdorff 维数为 1/2。甚至要求 Δ_j 最终恒等于 3，并要求 k(j) 与 j 最终始终异奇偶，仍有相同维数。

上界：Δ_j 最终一致有界推出 k(j)≤Cj 最终。对大 n 令 j=⌊n/(2C)⌋，则 d_n>H_j，所以 (log d_n)/n→∞。对 s>1/2 选 1/2<t<s。覆盖所有长 n 的 CF 柱，其长度≤d_n^(−2)，而 d_n≥∏_{i=1}^n a_i，故所有柱的 t-成本总和≤ζ(2t)^n。固定 M 足够大，限制 d_n≥exp(Mn) 的词，其 s-成本≤[ζ(2t)exp(−2(s−t)M)]^n→0。对满足该限制的起始指标作可数并即得上界。

下界：选择大 N，从一个已越过 H_N 的柱开始，其末数字为4，分母 u 与 H_N 可比，前分母 v≤u/4；其前一个指标即 k(N)，取与 N 异奇偶。初始柱可从任一小分母前缀选一个大数字落在 [H_N/3,H_N/2]，并用该末有理数的两种展开调整指标奇偶，然后补4。设 T=H_{j+1}，从当前父词附加 [1,m] 两个数字，其末分母为 t_m=m(u+v)+u；选取全部使 T/3≤t_m≤T/2 的整数 m，至少有 cT/u≥c′j 个。其后补4，新的分母落在 [4T/3,5T/2]，于是 t_m 的指标恰为 k(j+1)，比上一个末指标增加3。补4后的不同子柱有不同前缀，其内部不交，长度一致约为 T^(−2)。每个父柱取等概率分支。层 n 父柱质量≤exp(−n log n+O(n))；长度 h∈[H_{n+1}^(−2),H_n^(−2)] 的区间至多遇到 O(1) 个父柱。任意 s<1/2，因 log H_{n+1}=n log n+O(n)，质量≤h^s 最终成立。质量分配给出下界，删去可数有理端点不影响结果。因 Q+Qe 也可数，删去所有与 1,e 线性相关的点后维数仍为 1/2。

正式主稿应单独核查这一命题与已知“无穷 Lyapunov 指数”维数1/2结论的关系；不声称一般上界是首创。这里的下界针对项目所用的具体窗口与 Δ_j=3 的精确合取要求。
